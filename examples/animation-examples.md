# Animation examples

Open any `.apoproject` below in the desktop editor, then open its Animation Timeline. All examples use the built-in renderer variations, 61 frames at 30 fps and the full 64-bit-capable fixed seed field set to `123456`.

| Project | Motion and settings |
| --- | --- |
| [animation-orbit.apoproject](animation-orbit.apoproject) | Full 360° camera rotation around the current view center; unwrapped degrees; repeat playback |
| [animation-zoom.apoproject](animation-zoom.apoproject) | One-stop zoom (2× camera density); ping-pong playback |
| [animation-palette.apoproject](animation-palette.apoproject) | Four palette quarter-turns returning to the original palette; linear-light RGB crossfades; repeat playback |
| [animation-morph.apoproject](animation-morph.apoproject) | Ember spiral to midnight spiral; explicit `spiral`, `julia`, `petal` correspondence; polar affines; smootherstep easing; linear-light palette interpolation |

The morph's source artwork is [ember-spiral.flame](ember-spiral.flame) and [animation-morph-target.flame](animation-morph-target.flame). Both source snapshots are retained inside the project, so the project is self-contained. The standalone target remains available for inspecting or changing the final pose.

## Try a short sequence

From the repository or extracted project root, substitute your native build
directory for `build`. With the Windows package in Git Bash, replace
`./build/flame-cpu` with `./bin/windows-x64/flame-cpu.exe`.

```bash
./build/flame-cpu animation inspect examples/animation-morph.apoproject

mkdir -p morph-frames
./build/flame-cpu animation render examples/animation-morph.apoproject \
  --output-dir morph-frames --prefix morph --first 0 --last 60 --step 10 \
  --width 640 --height 480 --samples 1000000 --threads 1 --format png8 --estimate

./build/flame-cpu animation render examples/animation-morph.apoproject \
  --output-dir morph-frames --prefix morph --first 0 --last 60 --step 10 \
  --width 640 --height 480 --samples 1000000 --threads 1 --format png8
```

This renders seven frames with global indices `000000`, `000010`, ..., `000060`. Remove `--step 10` for all 61 frames. The terminal frame belongs to the export range; it is not omitted merely because a repeat preset has visually matching first/last poses. Use an explicit range if your downstream playback needs to omit the terminal duplicate.

## Recreate the projects

These projects were generated by the M9 CLI, not by a separate handwritten serializer:

```bash
./build/flame-cpu animation create examples/ember-spiral.flame \
  --preset camera-orbit --frames 61 --fps 30 --seed 123456 --name 'Ember orbit' \
  --output orbit.apoproject

./build/flame-cpu animation create examples/ember-spiral.flame \
  --preset zoom --frames 61 --fps 30 --seed 123456 --name 'Ember zoom' \
  --output zoom.apoproject

./build/flame-cpu animation create examples/ember-spiral.flame \
  --preset palette-cycle --frames 61 --fps 30 --seed 123456 \
  --name 'Ember palette cycle' --palette linear-rgb --output palette.apoproject

./build/flame-cpu animation morph examples/ember-spiral.flame \
  --to examples/animation-morph-target.flame \
  --from-ids spiral,julia,petal --to-ids spiral,julia,petal \
  --frames 61 --fps 30 --seed 123456 --name 'Ember to midnight' \
  --easing smootherstep --palette linear-rgb --output morph.apoproject
```

Every example passed complete 0–60 frame export preflight with a fixed test canvas. Higher resolutions and sampling budgets remain subject to the normal render-resource checks. See [the CLI guide](../docs/ANIMATION_CLI.md), [timeline format](../docs/ANIMATION_MODEL.md) and [morphing rules](../docs/MORPHING.md).
