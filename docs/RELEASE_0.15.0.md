# Apophysis Reborn 0.15.0

## Personal flame favorites

Click the star in the Flame library to keep an editable copy of the selected flame. Add tags to make it easy to find again. Click **Favorites…** in any project, find the entry by its name or tags, then insert a copy. Editing or undoing that copy leaves the saved favorite intact.

## Visual variation explorer

Open **Flame → Variation explorer…** or use the button in the **Variations** panel. Choose a built-in variation, a control and a range. Compare its labeled previews on the current transform, then apply one value. The previews hold the render seed fixed. Closing the dialog discards pending edits. **Ctrl+Z** undoes an applied change.

## Try this build on Windows

1. Close the previous editor and run the x64 installer, or extract the portable ZIP and launch **apophysis-reborn.exe**.
2. Use **Ember spiral** to try the [favorites and variation walkthrough](USER_MANUAL.md#favorites-and-variation-explorer). Reopen a saved favorite with a different project after restarting.
3. Try a second range while previews are rendering. Close the explorer, save the project, reopen it and verify the selected value is present.
