This inventory covers work through the animation and color checkpoint. The CLI and core API retain CPU defaults; new saved desktop settings select Automatic with CPU fallback. Plugin variations explicitly require CPU evaluation. The M9 full native suite contains 39 entries; exact executed results and boundaries are in [TEST_PLAN.md](TEST_PLAN.md). Software Vulkan execution establishes no physical-GPU speedup.

Milestone 10 is next: release hardening, packaging and the remaining platform acceptance. M9 defines a Reborn animation format and explicit timed-library import; unknown/future animation payloads still survive without reinterpretation. The delivered 7X curves reproduce the checked original numerical behavior; this is not complete 7X/AV feature parity. The full historical scripting surface, direct old binary-plugin loading, additional native variations, arbitrary Ultra Fractal formulas and broader original-application reopen audits remain open. JPEG/OpenEXR output, ICC color management and dithering also remain open. Queue restoration is stopped until explicitly started, old checkpoints are retained for manual cleanup, and operating-system shutdown after rendering is not implemented.
