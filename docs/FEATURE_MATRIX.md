This inventory covers work through the high-resolution rendering checkpoint. The CLI and core API retain CPU defaults; new saved desktop settings select Automatic with CPU fallback. Both full native Release and ASan/UBSan suites contain 25 passing entries. A Vulkan-disabled core build passes 16 checks and skips three device-execution checks. [TEST_PLAN.md](TEST_PLAN.md) keeps executed results separate from platform limitations. Software Vulkan execution establishes no physical-GPU speedup.

Milestone 8 is next: scripting, plugins and additional historical formats. The menu, dialog, variation and file-format inventories by historical release still require broader audit of original 2.x, 7X and AV sources and applications. JPEG/OpenEXR output and profile-based color management remain open; PNG/TIFF16 and straight alpha do not imply completion of every final-product export feature. Queue restoration is deliberately stopped, old checkpoints are retained for manual cleanup, and operating-system shutdown after rendering is not implemented.
