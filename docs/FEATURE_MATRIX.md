The CLI and core API retain CPU defaults; new saved desktop settings select Automatic with CPU fallback. Native plugin variations require CPU evaluation. The M10 configuration registers 48 full CTest entries or 36 core-only entries; a Vulkan-disabled core run expects three device-execution skips. An inventory is not a pass result. Exact final execution, source/binary identity, stage audits and measurements are in [TEST_PLAN.md](TEST_PLAN.md), `BUILD.txt` and packaged `verification` records. Earlier suite totals and 16K timings remain historical.

Continue with the targeted work in [RELEASE_HANDOFF.md](RELEASE_HANDOFF.md). All 40 variations named in the original brief are available. Further historical estimator profiles, broader 3D/direct-color/filter behavior, full historical scripting/animation and arbitrary Ultra Fractal formulas remain incomplete. Export/color-management, light-theme/workspace/preferences and failure-isolation gaps remain explicit in the requirement register. The delivered 7X curves reproduce the checked original numerical behavior; they do not establish complete renderer parity. Unknown/future animation data continue to survive without reinterpretation. Queue restoration stays stopped until explicitly started, completed checkpoints are retained for manual cleanup, and shutdown-after-rendering is not implemented.
