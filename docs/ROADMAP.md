## 0.17.0 scope

- **Animation editing.** Add keyframes and interpolation controls for individual properties. Existing clips should open and play as before.
- **Classic flame compatibility.** Use real legacy files to select missing 2D variations for this build. Compare CPU and Vulkan output against reference renders and document files that require 3D or direct color.
- **Video export and composition.** Compose independent flame layers with separate palettes and transforms. Render the composition as a frame sequence and encode the finished sequence to MP4.

Build deliveries include the download, changes, test results, outstanding platform checks, and the current roadmap. Update this table when a milestone ships or priorities change.
