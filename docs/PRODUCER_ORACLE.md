# Original Pascal image and field comparisons

The pixel references were generated by compiling the original Apophysis 2.09 and 7X Pascal image-maker methods independently under Free Pascal 3.2.2 on x86-64 Linux. The generator extracts the complete `CreateFilter`, `NormalizeFilter`, `SafeGetBucket` and `CreateImage` method bodies from each source tree. For 7X it also compiles `InitDE` and the original `Bezier.pas` unit. SHA-256 checks pin the external sources. The harness supplies ordinary in-memory bitmap scanlines, an already accumulated histogram and control-point values. The original methods compute the Gaussian kernels, log-density exposure, gamma threshold, vibrancy, background composition and final pixel quantization.

| Test case | Oversample | Filter radius | Gamma threshold | Gaussian width | Center pixel RGB |
| --- | ---: | ---: | ---: | ---: | --- |
| direct | 1 | 0 | 0 | 1 | 111, 74, 55 |
| low | 1 | 0 | 0.8 | 1 | 88, 67, 63 |
| gaussian | 1 | 0.75 | 0.05 | 3 | 110, 73, 55 |
| even | 2 | 0.5 | 0.15 | 4 | 78, 60, 59 |
| wide | 3 | 0.8 | 0.4 | 9 | 34, 42, 66 |

The Pascal outputs from both producers agreed byte-for-byte on all five 8 × 6 images and all 107 coefficient positions across the four distinct filters. The Reborn test renders the five flames through the CLI, once with each producer label, and compares complete P6 files against the saved reference. Both labels matched every RGB channel. Nominal brightness is 0.14, gamma 2.2, vibrancy 0.75 and the background is RGB8 (16, 32, 64). The single constant-position transform places all 9,600 samples in the center bucket, with a flat RGB8 palette (192, 96, 32). This isolates a known histogram and provides a direct test of reconstruction without RNG or orbit differences.

The corpus tests separately cover imported artwork. These controlled references exercise opaque 2D output with density estimation disabled and identity curves. They do not establish image equivalence for arbitrary stochastic flames, original Windows GUI operation, or AV-specific image processing.

## Reproduce the reference images

Obtain the original 2.09 source archive (archive SHA-256 `c302b44194e3552999b5279c30900876e2063587e0137af02a3cad4caaec395a`) and 7X commit `1cefa4099927e296d365412bd0b91b96f85606ca`. The generator expects their extracted source roots. Preserve upstream file bytes and line endings. Both source trees are used only by the optional regeneration tools. [Original Apophysis 2.09 source archive](https://downloads.sourceforge.net/project/apophysis/apophysis/Apophysis%202.09/Apophysis-2.09-src.7z) · [7X source snapshot](https://github.com/xyrus02/apophysis-7x/tree/1cefa4099927e296d365412bd0b91b96f85606ca)

Run from the Reborn source root with Python 3 and Free Pascal 3.2.2 on PATH. An alternate compiler plus unit search flags can be supplied in the `FPC` environment variable.

```bash
python3 tests/legacy/producer-oracle.py /path/to/apophysis-209 /tmp/apo209-reference
python3 tests/legacy/producer-oracle.py /path/to/apophysis-7x /tmp/apo7x-reference
diff -rq /tmp/apo209-reference /tmp/apo7x-reference
for file in /tmp/apo209-reference/producer-oracle-*; do
    cmp "$file" "tests/legacy/$(basename "$file")" || exit 1
done
```

## Reopen saved and exported fields with 2.09 source routines

The field check also compiled the original 2.09 `GetTokens`, `ParseCompactColors`, size/center/scale parsing statements and indexed-color parsing statements from `cmap.pas` and `Main.pas`. Python's XML reader supplies decoded attributes and palette element text to the Pascal routines. The original Apophysis distribution's third-party XML scanner and Windows form are outside this harness.

The check read the first *Spherical* entry from the publisher-distributed 2.08 beta 2 collection, applied three edits with Reborn's `save`, then used `export` to create a standalone file. Apophysis's code recovered the edited size (321 × 123), center (0.125, −0.3125) and scale (42.625) from both outputs. It decoded all 768 palette channel bytes identically across the original packed palette, the saved collection, and the standalone indexed-color export. A second run on the bundled oracle collection produced the same field and palette checks.

```bash
python3 tests/legacy/producer-oracle-read.py /path/to/apophysis-209 ./build/flame-cpu tests/legacy/producer-oracle.flame
# To repeat the published-file check, pass the 7X archive's Apophysis7X.temp as the final argument.
```
